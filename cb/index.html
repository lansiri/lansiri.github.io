Safety properties of this page. It issues no network request of any kind; it reads location.hash and location.search once, then calls history.replaceState() so the credential is removed from the address bar. No token value is ever rendered in full, written to storage, or transmitted. The downloadable evidence JSON contains only prefixes, lengths and hashes.
